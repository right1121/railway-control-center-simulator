# Milestone 1: Simulation Core 安定化

Milestone 1 の必要タスク一覧。

## A. 仕様の固定（ドキュメント & ルール定義）

### 終端挙動の仕様決定

- 現状: 終端到達で `PendingTurnback` → 次 `Tick` で方向反転（折返し仕様）
- `AGENTS.md` には「終端停止」寄りの記述がある
- 正式仕様を一本化し、コードとドキュメントを一致させる

### 駅 = ブロック境界の仕様を明文化

- 「駅にいる状態は持たない」
- `progress == 0` or `1` が駅境界
- 境界到達時の振る舞い（停止の意味 / 次ブロック遷移条件）を定義

### Tick の決定論（determinism）条件を書く

- 同じ初期状態 + 同じ入力（`dt`） -> 同じ結果
- Domain ではランダム禁止、`time.Now` 禁止
- 列車の更新順序を決定する（`map` 走査に依存しない）

## B. Domain API の穴埋め（UI/DTO が推測しないようにする）

### 駅境界判定 API の追加

- 列車が駅境界にいるかを返す Domain API を追加
- 例: `TrainStation(trainID) (stationID, ok)`
- 例: `IsAtBoundary(trainID) bool` / `BoundaryStation(...)`
- 目的: UI/DTO が `progress == 0/1` を直接見て推測しない

### 進行可否 API（任意）

- 「次に進めるか」を返す補助 API を検討
- 例: `CanEnterNextBlock(trainID) (bool, reason)`
- `reason` 例: `occupied`, `terminal`, `no_next_block`
- 注: Departure Permission は Milestone 2 なので、Milestone 1 では占有・終端のみ対象

## C. Invariants（不変条件）をコードで閉じる

### 占有管理の一元化

- `occupy/release` の責務を集約
- `Tick` 内に散っている更新を `occupyBlock`, `releaseBlock`, `moveOccupancy` のような関数で集中管理
- 「1ブロック = 1列車」を破るコード経路を物理的に潰す

### 列車追加（初期配置）の不変条件

- 初期ブロックが占有済みならエラー
- `progress` が `0..1` に収まる
- `speed > 0`
- 直線路線に対して `blockID` が存在する
- `trainID` 重複禁止

## D. テスト強化（Milestone 1 の本体）

### Tick 基本ケースをテーブルドリブンで固定

- ブロック内で進む（境界未到達）
- 境界にちょうど到達する
- 境界を超える（`overflow` が次ブロックへ繰り越される）
- 複数ブロックを 1 回の `Tick` で跨ぐ（大きい `dt`）

### 占有衝突の固定テスト

- 次ブロック占有中 -> 境界で停止（`progress` を `0/1` にクランプ）
- 停止後、次ブロックが空いたら次 `Tick` で進む（Milestone 1 では occupancy のみ）

### 終端挙動テスト（仕様決定に合わせる）

- 折返し仕様の場合
  - 終端到達 -> `pendingTurnback = true`
  - 次 `Tick` で方向反転し、逆方向に進む
- 終端停止仕様の場合
  - 終端到達 -> `stopped = true` で永続停止
- どちらの場合も「テストが仕様書」になるように作る

### 決定論テスト

- 同一初期状態で複数回 `Tick` -> 結果が一致
- 列車更新順序が `map` に依存して揺れないこと
- `map` 走査している場合は `[]TrainID` をソートして処理順固定

## E. DTO / UseCase の安定化（MVP 境界を綺麗に）

### SimulationDTO の明示化

- `SimulationDTO` に駅境界情報を含める（推測禁止）
- 例: `atStation: true/false`, `stationId`, `stationName`
- Domain API を整えた後に DTO 化する

### エラー型の固定

- `domain -> usecase -> http` のエラー変換を固定
- Milestone 1 では `invalid tick delta` / `invalid state` 程度でよい
- 500 に丸めず、最低限 400 を返せる形を整える（Milestone 4 で拡張）
